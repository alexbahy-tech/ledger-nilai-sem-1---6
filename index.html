Pengaturan

Konfigurasi koneksi ke Google Sheets dan Google Apps Script

table_chartGoogle Sheets (CSV — Read Only)

Spreadsheet harus diset "Anyone with link → Viewer".

cloud_uploadGoogle Apps Script Web App (Write)

Paste isi Code.gs yang sudah diperbaiki, lalu deploy sebagai Web App.

codePanduan Deploy Code.gs

  1. Buka spreadsheet → menu Extensions → Apps Script
  2. Hapus semua kode lama yang ada di editor
  3. Paste seluruh isi file Code.gs yang baru → klik Save (Ctrl+S)
  4. Klik Deploy → New Deployment
  5. Pilih type: Web App, atur:
    • Execute as: Me
    • Who has access: Anyone
  6. Klik Deploy → authorize → copy URL yang muncul
  7. Paste URL di field "URL Web App" di atas → Simpan → Tes Koneksi
warning PENTING: Setiap ganti kode Code.gs, wajib buat New Deployment baru (bukan Redeploy versi lama). Update URL baru di Pengaturan ini.
